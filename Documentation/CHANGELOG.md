## [0.1.0] — 2026-08-31

First release.

### Added

- Native macOS application: window, `WKWebView`, private `earlocal://` scheme serving the interface from disk.
- `SerialBridge` — SDP lookup of the device's custom SPP service, RFCOMM channel, protocol frame reassembly, silent reconnect after idle disconnects, outbox with a time to live and per-service tagging.
- `shim.js` — nine members of the Web Serial API implemented over `webkit.messageHandlers`, including two deliberate deviations from the specification that match how the interface actually uses it.
- Device identification cache: the model-reporting channel answers only right after connecting, so the answer is stored per device address and replayed afterwards.
- `SiteUpdater` — update check by `Last-Modified` and size, full site mirroring, and pruning so only one copy is kept.
- `build.sh` with `--test` and `--install`, an original application icon generated by `Tools/make-icon.swift`, and CI that fails if any upstream file ends up in the bundle.
